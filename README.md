# Data Jobs Dashboard (Power BI)
 ![dashboard page 1](/images/page%201.png)

An interactive Power BI dashboard analyzing 15,000+ data job postings from 2024 — covering salary trends, job distribution, remote work patterns, and hiring platforms, with drill-through detail pages per job title.

## 🔍 Overview

This project explores what the data job market actually looked like in 2024: which roles pay the most, where jobs are concentrated globally, how postings trended month over month, and what benefits/work arrangements are most common by role.

## 📊 Features

**Main Dashboard**
- KPI cards: total job count, median yearly salary, median hourly salary, salary star rating
- Monthly job posting trend for 2024
- Highest-paying job titles (Data Engineer, Data Analyst, Data Scientist, Senior variants)
- Hourly vs. yearly salary scatter comparison
- Sortable summary table (job count, yearly salary, hourly salary, monthly trend by role)

**Drill-Through Page (per job title)**
- Hourly and yearly salary gauges with min/max ranges
- Work-from-home (WFH) split
- Degree requirement breakdown
- Health insurance inclusion rate
- Global map of job postings by location
- Top hiring platforms (LinkedIn, Indeed, BeBee, ZipRecruiter, etc.)
- Job type breakdown (full-time vs. other)

## 🛠️ Tools & Skills Used

- **Power BI** — data modeling, DAX measures, drill-through pages, interactive visuals (gauge, treemap, scatter, filled map, matrix)
- **Power Query** — data cleaning and shaping
- **SQL** — initial data exploration and validation
- **Excel** — early-stage data checks

## 📈 Key Insights

- Job postings peaked mid-2024 (~1.5K/month) before a sharp decline toward Q4
- Data Engineer and Data Analyst roles had the highest posting volume
- Median yearly salary for senior data roles clustered around $107K
- LinkedIn is the dominant platform for data job postings, far ahead of Indeed and other boards
- The vast majority of postings are full-time with no explicit remote requirement
